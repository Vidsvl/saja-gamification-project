Plataforma educacional com gamificação focada em engajamento e aprendizado consistente. Sistema completo com:
- 2 sistemas de pontos (Sabedoria + Moedas de Esforço)
- 3 Leaderboards distintos (Consistência, Maestria, Colaboração)
- Progressão em 5 níveis por matéria
- Recompensas digitais + acadêmicas/físicas
- Stack: Web responsiva (HTML5/CSS/JS) + Backend (Python/Node.js)
